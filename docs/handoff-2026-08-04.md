### The five entry sources, and the rule they share

`TriggerChainEntry.source` is `"event"` (a bystander on the board) | `"unitOnPlay"`
| `"unitOnMove"` | `"selfTrigger"` | `"deathknell"`. **Every one of them now
resolves even though its card has left play**, which is a correction dated
2026-08-04 — see below.

### Three mechanisms worth knowing before touching this

- **`applies`** decides whether an ability TRIGGERED, at the moment of the event.
  383.4.f states the rule outright: "if the trigger condition contains other
  requirements besides attacking and if those requirements are not fulfilled when
  the unit gains the Attacker designation, it will not trigger in that combat."
  A condition about the BOARD at resolution stays in `resolve`.
- **`capture` / `captureEach`** carry what the event cannot: which unit an ability
  singled out (`capture`, Mask of Foresight), or one Pending Item per subject
  (`captureEach`, Ahri's per-attacker debuff).
- **`listenerCard`** carries the listener so resolution always has one.

## The one big thing left, and why it is not started

**Pending vs Finalized — rule 402's steps 2 through 4 do not exist.** 402 gives
finalization four numbered parts: add the Pending Item (this exists); *make
relevant choices* — the "you may", the targets, and "if there are not enough
options to make legal choices … remove it from the Chain now"; determine total
cost; pay costs, which may be declined.

Measured: **17 cards ask their question at RESOLUTION** where 402 puts it at
finalization, and seven more auto-select a target rather than choosing one.

**The blocker is structural and is not about the triggers.** Finalization happens
inside `cleanup.finalizePendingTriggers`, and a Cleanup cannot stop to ask
anything — `withCleanupAndWinnerCheck` returns from `submit` *before* running the
Cleanup whenever the decision queue is non-empty, which is 321 doing its job.
Asking at finalize needs the Cleanup to become a resumable state machine that can
suspend mid-step and continue on the answer: the same shape, and the same size, as
the turn-advance state machine the turn-boundary row already names. **Do not move
one card's question earlier without that** — it would mean parking a decision from
inside a Cleanup documented as unable to hold one.

## Discipline (standing, non-negotiable)

- **Prove every fix by making the check fail first.** A test that passed before
  the change tests nothing.
- **Fix the PREMISE, never weaken the assertion.**
- **An instrument gets the same scrutiny as the code.** Four instrument defects
  this session, every one reporting plausibly: the trigger census wrong four times
  by trusting one source of a list the engine merges from several; the live probe's
  deck generator printing "priority present" for cards the fill loop had silently
  dropped; the same probe recording a failed title read as a decision titled `""`;
  and `DECK=calm` failing a gate it cannot satisfy in six games.
- **A mutation that does not fail has proved nothing — and check it APPLIED.**
  Twice this session a patch script missed on indentation and the "mutation" ran
  against unmutated code. Grep for the marker. A mutation inserting
  `(undefined as T) ??` into a `??` chain is likewise a no-op.
- **Negative controls belong on the PEN, not the board.** A listener whose
  `applies` is wrong still re-checks in `resolve` and resolves to nothing, so the
  board is identical either way. Only `pendingTriggers` distinguishes "was not
  placed" from "was placed and did nothing".
- **Re-read the CODE before believing a note about the code.** Volibear's recorded
  blocker was false; so was the bystander rule; so was the "7 legend hooks" count,
  twice.
- **Record divergences in `docs/rules-conformance.md` in the same change.**
- **Never bulk-edit source with PowerShell.** A python round-trip with explicit
  `utf-8` and `newline=""` is safe — and note the repo is CRLF, so a multi-line
  search string joined with `\n` will silently not match.
- Scratch files go in the session scratchpad, NOT next to the source. A
  `__pycache__` reached a commit this session and had to be removed in the next.
- Commit per task with a real message, and push.

## Verification loop — every time, in this order

1. `npm run test --workspace=@rift-engine/engine`
2. `npm run build --workspace=@rift-engine/engine` — **before** the web typecheck,
   because `@rift-engine/web` resolves the engine from `dist`
3. `npm run typecheck`, then `npm run build`
4. Probes: `npx tsx packages/engine/probes/{ai-health,passive-human,chain-depth,walkout}.ts`
5. Live if a player can see the change: `PORT=<port> node
   tools/ui-probes/live-triggers.mjs` with `SPECTATE=1`, and
   `DECK=buff|calm|combat`. Never hardcode 5173. **Measure whether the deck can
   reach your change before trusting a green run** — three times this session a
   family was invisible to every live deck.
